# Customer Churn Analysis

**Business question:** Identify customers likely to leave a subscription service.

**Stack:** Python, pandas, matplotlib; see `requirements.txt` in the parent directory.

## Run
From this project folder, run:

```bash
python analyze.py
```

The script reads `data/` and writes a chart and `summary.txt` into `output/`.

**Data:** Synthetic practice data generated for this portfolio; not real customer or financial records.
